How to Use TonyGitLens

Complete step-by-step instructions for installing, reloading, and mastering TonyGitLens — the lightweight, GitLens-inspired VS Code extension for exploring Git worktrees, commits, and branch differences.

⚡ Quick Start (3 Steps)

1

Locate the VSIX Package

The extension is packaged in the root of the repository as tonygitlens-0.1.0.vsix (only ~15 KB).

2

Install into VS Code

Right-click tonygitlens-0.1.0.vsix in your VS Code Explorer sidebar and select "Install Extension VSIX".

3

Reload VS Code Window

Press Ctrl + Shift + P, type Developer: Reload Window, and hit Enter. The TonyGitLens icon appears immediately in your Activity Bar!

🌐 GitHub Repository

The full source code, issue tracker, commit logs, and documentation are hosted on GitHub:

Official Repository URL

🔗 https://github.com/TonyHo722/TonyGitLens

📦 How to Install the Extension

🖱️ Option A: Explorer Right-Click (Recommended)

1. Open the file explorer in VS Code.
2. Right-click tonygitlens-0.1.0.vsix.
3. Click "Install Extension VSIX".
4. Wait 1-2 seconds for the confirmation popup.

⌨️ Option B: Command Palette

1. Press Ctrl + Shift + P.
2. Type Extensions: Install from VSIX... and press Enter.
3. Select tonygitlens-0.1.0.vsix from the file dialog.

💻 Option C: Terminal Command (CLI)

If you prefer using the command line, run:

code --install-extension /home/tonyho/workspace/vscode_ext/tonygitlens-0.1.0.vsix

🔄 How to Reload / Restart VS Code

When you install or update a local .vsix extension, VS Code needs to reload its Extension Host.

Fastest Method: "Developer: Reload Window" (Takes 1 second)
  1. Press Ctrl + Shift + P (or Cmd + Shift + P on macOS / F1).
  2. Type: Reload Window
  3. Press Enter.

Note: This reloads only the editor window instantly without closing your tabs or terminals!

Extensions Panel Reload

Open the Extensions tab (Ctrl + Shift + X). If a blue "Reload Required" button is shown next to TonyGitLens, click it.

Full Application Restart

Close VS Code completely (Ctrl + Q or File > Exit) and reopen the workspace.

🔀 Feature 2: 1-Click Branch Compare (GitLens Style)

You do not need to pick 2 branches from scratch. Comparison is context-anchored directly to the branch you are inspecting:

How to Compare Branches in 1 Click
  1. Expand any worktree branch (e.g. main or feature-auth).
  2. Click the entry directly below the branch: 🔀 Compare '' with... (or the inline $(git-compare) icon on the worktree row).
  3. A single QuickPick appears with your other local and remote branches. Select your target branch (e.g. 0906test).
  4. The comparison immediately renders right below that branch!

The comparison also populates the dedicated Compare Branches panel, equipped with title bar actions: ⇄ Swap, ↻ Refresh, and ✕ Clear.

✕ How to Clear Comparisons for Each Branch

TonyGitLens provides 5 quick ways to clear an active branch comparison so you can return your tree view to its default clean state whenever you finish inspecting changes:

🖱️ Method 1: Inline ✕ Button on Hover (Fastest)

Hover your mouse over the active comparison item:
Compared with '<branch>'
Three inline action buttons appear on the right. Click the ✕ (Clear Comparison) button.
The comparison section immediately collapses and resets back to Compare '<branch>' with...!

📋 Method 2: Right-Click "Compared with..."

Right-click directly on the Compared with '<branch>' row in the tree view and select "Clear Comparison" from the context menu.

🌿 Method 3: Right-Click the Branch / Worktree

Right-click the parent branch row (e.g. 🌿 main) and select "Clear Comparison". This clears any active comparison attached to that branch.

📁 Method 4: Right-Click Comparison Sub-Sections

Right-click any sub-item inside the comparison (such as Files Changed, Commits Ahead, or Commits Behind) and select "Clear Comparison".

🧹 Method 5: Title Bar "Clear All Comparisons"

Click the $(clear-all) icon in the header toolbar of the Worktrees panel to dismiss all active branch comparisons across all worktrees at once.

⌨️ Method 6: Command Palette Picker

Press Ctrl + Shift + P and run TonyGitLens: Clear Branch Comparison.
If multiple branches are being compared, an interactive QuickPick lets you choose which branch to clear or select "Clear All Branch Comparisons".

💡 Bonus: More Actions on Active Comparisons

When hovering over Compared with '<branch>', you can also:

  • $(arrow-swap) Swap Base & Target: Reverses comparison direction in-place without re-selecting branches.
  • $(git-compare) Change Target: Select a different branch to compare against without clearing first!

🔍 Feature 3: Native Side-by-Side Diffs

Clicking on any changed file under a commit or under Files Changed automatically triggers VS Code's native diff editor:

  • Zero Temporary Disk Files: Powered by virtual documents under the custom tonygitlens:// URI scheme.
  • Full Revision Accuracy:
    • Modified Files: Compares base branch revision against target branch revision.
    • Added Files: Compares an empty virtual document against the new file.
    • Deleted Files: Compares the previous file contents against an empty document.
