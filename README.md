# TonyGitLens

Fast, lightweight GitLens-inspired VS Code extension for viewing Git worktrees and commits.

## Features

- **Worktree Explorer**: View all main and linked worktrees at a glance.
- **Commit History**: View commits per worktree with author, date, and commit SHA.
- **Changed Files & Diffs**: Inspect modified files and open side-by-side diffs using VS Code's native diff viewer.
- **Worktree Actions**: Open worktrees in a new window, reveal in OS file explorer, or copy commit SHAs.

## Development

- Press `F5` to launch Extension Development Host.
- Run `npm test` to run automated tests.
- Run `npm run package` to compile production bundle.
